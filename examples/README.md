# Beispielaufnahme

`sample_recording/ERP_demo_stimulation.csv` — gut fünf Minuten, 8 Kanäle, 250 Hz, 47 Trigger
(Stoßwellen-Reiz am Fuß, Noise-Cancelling-Kopfhörer). Zum Verkleinern sind nur die Rohkanäle
(`raw_*`) und auf eine Nachkommastelle gerundet enthalten; das genügt für Replay und Offline-Auswertung.
Format: siehe `core/session_recorder.py`.
